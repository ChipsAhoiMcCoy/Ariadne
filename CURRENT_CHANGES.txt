Current changes
===============

Terrain sensing and sound
-------------------------
[ ] A lone block directly overhead is detected as a ceiling.
[ ] Blocks two tiles up and two tiles sideways are not detected as ceilings.
[ ] Ceiling detection still works with inverted gravity, slopes, and half-blocks.
[ ] Pass-through platforms are not treated as ceilings.
[ ] Side walls use a broad 280-1,800 Hz white-noise filter with Q 1.0.
[ ] Ceilings use a narrow 900-4,200 Hz white-noise filter with Q 3.0.
[ ] Falling ground uses a broad low 140-850 Hz white-noise filter with Q 0.7.
[ ] The three terrain timbres have similar perceived loudness.

Interaction targeting
---------------------
[ ] An unlocked cursor activates an interactable entity directly under it first.
[ ] Otherwise, an unlocked cursor activates the exact tile or multi-tile object.
[ ] A nearby NPC does not steal interaction from a targeted chest above platforms.
[ ] Smart Cursor honors Terraria's genuine tile or NPC target first.
[ ] Smart Cursor uses proximity conversation only when it has no genuine target.
[ ] Chests, dressers, signs, tracks, and modded objects retain normal right-click behavior.
[ ] An Old Shaking Chest can be targeted through overlapping minecart tracks.
[ ] An Old Shaking Chest consumes a Golden Key from inventory or an open Void Bag.
[ ] An Old Shaking Chest transforms and synchronizes correctly in multiplayer.
[ ] Without a Golden Key, Ariadne announces that one is required.
[ ] Unlocked-cursor speech names a resolved entity instead of an overlapping tile.

Elevation movement cues
-----------------------
[ ] Climbing upward across a vertical tile boundary on a rope-like tile plays a brief rising centered tick.
[ ] Climbing downward across a vertical tile boundary on a rope-like tile plays a brief falling centered tick.
[ ] Ordinary jumps, falls, mounts, grappling-hook pulls, and other vertical movement remain silent.
[ ] Detaching and grabbing another climbable does not report crossings accumulated in between.
[ ] No more than ten elevation ticks play per second during fast climbing.
[ ] Excess crossings during fast climbing are discarded instead of queued.
[ ] Teleports and other large discontinuities do not produce elevation ticks.
[ ] Elevation ticks stop or reset during pause, focus loss, menus, death, and world transitions.

Ledge and drop warnings
-----------------------
[ ] No ledge cue plays for a one- or two-tile drop.
[ ] A hazard-free three-tile drop plays one safe-drop cue.
[ ] A fall that would cause damage plays one unsafe-drop cue.
[ ] Spikes and modded hurting tiles play the unsafe-drop cue.
[ ] Lava and shimmer play the unsafe-drop cue.
[ ] No bottom within the configured detection range plays the unsafe-drop cue.
[ ] Wings, no-fall effects, extraFall, and fall-negating tiles affect safety correctly.
[ ] Holding toward the same ledge does not repeat its cue.
[ ] Retreating from the edge re-arms the cue.
[ ] Changing direction re-arms the cue.
[ ] Returning to supported terrain re-arms the cue.
[ ] Drop warnings run only while grounded and intentionally moving left or right.
