# Ariadne 1.0.0

The first 1.0 release of Ariadne, an accessibility mod for blind and low-vision Terraria players using tModLoader.

**Download `Ariadne.tmod` from Assets below. That is the only Ariadne file you need to install.**

## Requirements

- Terraria and tModLoader installed through Steam.
- **64-bit Windows 10 or later** for the bundled Prism speech/braille runtime.
- Built with **tModLoader 2026.7.3.0** (Terraria 1.4.4 line). This is the verified build version; compatibility with other tModLoader branches/versions has not been established.
- An active screen reader such as NVDA is preferred; available built-in speech fallbacks can also be selected by Prism. Braille support depends on the backend and screen-reader setup.

## Installation

1. Download **Ariadne.tmod** from this release's Assets.
2. Launch tModLoader and select **Workshop → Manage Mods → Open Mods Folder** to locate the active folder. The normal Windows path is `Documents\My Games\Terraria\tModLoader\Mods`; OneDrive/redirection and custom save paths may differ.
3. Close tModLoader and copy `Ariadne.tmod` into that folder. Do not unzip it or put it in Terraria's Steam installation folder.
4. Start your screen reader, launch tModLoader again, enable **Ariadne** in Manage Mods, and reload mods when prompted. If automatic reload is off, apply the pending reload manually.
5. Open **Ariadne Sound Guide** on the main menu to learn the cues. Press **Alt+H** for contextual help. In-game, the Sound Guide is also under Settings.

Ariadne's speech is unavailable before the mod is enabled, so first-time setup may require assistance. Prism, localization, and license notices are already inside the `.tmod`; no separate DLL, SDK, source checkout, or compiler is required. GitHub's automatic **Source code** downloads are not installable mods.

**Updating:** Back up your saves, close tModLoader, replace the previous `.tmod`, and reopen. Keep your own settings and mod-selection files. To uninstall, disable Ariadne and reload; its speech/accessibility will then stop.

## What's included

- Spoken character/world creation, multiplayer setup, achievements, settings, Workshop tools, and contextual help.
- Hierarchical inventory with item actions, equipment, shops, crafting, reforging, NPC services, and Journey tools. Ctrl+Tab moves between sibling panes; holding I repeats supported crafting recipes.
- Keyboard aiming and interaction, Smart Cursor, combat target cycling, and boss vulnerability feedback.
- Spatial wall/ceiling and enemy cues, radar, footsteps, climbing/ledge/landmark feedback, and an interactive sound guide.
- Visible-surroundings scanner with **teleport and interaction**, saved world waypoints, semantic map/pylon travel, Housing Query, and freecam with a body beacon.
- Spoken status, chat history, pickups, summons, biome changes, low health, breath, and death/respawn feedback.

## Quick controls

| Key | Action |
| --- | --- |
| A / D; W / S; Space | Walk; climb up/down; jump. |
| Alt+H | Contextual help. |
| O / K / L / ; | Aim up / left / down / right. |
| I / P | Primary use / secondary use or interact. |
| Tab | Cycle combat targets; after the farthest, release. |
| Escape | Inventory; close when open. |
| End / Apostrophe | Scanner / one manual radar contact. |
| Left Alt+W | Waypoints. |

| U | Housing Query. |
| Hold Right Shift + movement | Freecam; release to return. |

## Known boundaries and validation

Speech is packaged for Windows x64 only; localization is English. Generic third-party UI access is best effort. Scanner results are fixed snapshots of lit visible surroundings, not world-wide detection. Scanner/waypoint activation can teleport the player; servers can reject/correct travel. Ariadne is NoSync, so other clients and servers need not install it, but multiplayer does not pause while you browse menus. External Steam/browser/Explorer windows use their own accessibility.

Release checks: tModLoader build completed with **zero errors and warnings**; all **9 gameplay-logic and 13 spatial-audio harness checks passed**. The packaged version, archive integrity, embedded Prism checksum, and complete license resources were verified. The release was not given a new end-to-end interactive gameplay/screen-reader test during packaging.

Please [report issues](https://github.com/ChipsAhoiMcCoy/Ariadne/issues) with versions, screen reader, other relevant mods, and reproduction steps. See the player guide for troubleshooting and log locations.
