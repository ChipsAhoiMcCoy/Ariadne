# Ariadne settings reference

For 1.0.0. In-game, open Settings → Mod Configuration → Ariadne: Ariadne Accessibility Settings. At the title screen, use Workshop → Manage Mods → Mod Configuration or Ariadne's Config action. Choose Save changes to apply edits. Revert unsaved changes restores saved values; Restore defaults still requires saving. All options are client-side. Volumes scale Terraria's Sound volume; at zero Sound, cues are silent. Home and Left Alt+Apostrophe are session overrides rather than saved preferences. Changing the saved wall-tone setting clears its session override.

Every saved setting is listed below in configuration order. Internal names are included to help identify settings in ModConfigs. On/off settings accept true/false. Numeric ranges include both endpoints. Inventory column values fill balanced columns top to bottom.

| Setting (config name) | Default | Range / step | What it does |
| --- | --- | --- | --- |
| Biome announcements (`BiomeAnnouncementsEnabled`) | true | On / off | Announce a biome after the player has remained in it long enough to avoid rapid announcements at biome boundaries. |
| Cursor earcons (`CursorEarconsEnabled`) | true | On / off | Play the targeted tile or liquid's native Terraria sound for each nonempty unlocked-cursor step and each changed nonempty Smart Cursor target. |
| Cursor earcon volume (`CursorEarconVolumePercent`) | 70 | 0–100 / 5 | Set cursor-earcon loudness as a percentage of the game's Sound volume. |
| Cursor coordinate announcements (`CursorCoordinateAnnouncementsEnabled`) | true | On / off | Include tile coordinates in unlocked-cursor movement announcements. Smart Cursor never announces coordinates. |
| Player-relative coordinates (`RelativeCoordinateReadoutEnabled`) | true | On / off | Report positions as an offset from the player, who counts as zero, instead of as raw world tile numbers. Waypoint names always keep raw coordinates so they stay meaningful after you move. |
| Low health heartbeat (`LowHealthHeartbeatEnabled`) | true | On / off | Pulse a synthesized heartbeat once health falls to half, quickening it at each lower threshold down to five percent. |
| Low health heartbeat volume (`LowHealthHeartbeatVolumePercent`) | 70 | 0–100 / 5 | Set heartbeat loudness as a percentage of the game's Sound volume. The beat still grows louder as health falls. |
| Low health announcements (`LowHealthAnnouncementsEnabled`) | true | On / off | Speak the remaining health percentage each time health crosses into a lower threshold, and confirm once health has recovered. |
| Breath announcements (`BreathAnnouncementsEnabled`) | true | On / off | Announce submersion and each ten percent of remaining breath, paired with Terraria's own splash sound. |
| Hotbar selection announcements (`HotbarAnnouncementsEnabled`) | true | On / off | Speak the item and slot number whenever the selected hotbar slot changes, and again when the selected slot's contents change, such as a stack running out. |
| Item pickup announcements (`ItemPickupAnnouncementsEnabled`) | true | On / off | Speak each item that reaches the inventory, including fishing catches. Repeated gains of the same item are collected for a moment and reported as one running total, and coins are merged into a single value. |
| Summon announcements (`SummonAnnouncementsEnabled`) | true | On / off | Speak newly summoned minions and sentries, followed by the active total and used capacity. Removals remain silent. |
| Inventory columns (`InventoryColumnCount`) | 1 | 1–10 / 1 | Set the number of top-to-bottom columns used by the 40 backpack slots, coin, and ammo panes. Trash is appended beneath slot 40 in the final backpack column and is not included in column division. One preserves the original vertical list. |
| Hotbar columns (`HotbarColumnCount`) | 1 | 1–10 / 1 | Set the number of top-to-bottom columns used by the accessible hotbar pane. One preserves the original vertical list. |
| Crafting columns (`CraftingColumnCount`) | 1 | 1–10 / 1 | Set the number of top-to-bottom columns used by normal and Guide recipe lists. One preserves the original vertical list. |
| Storage columns (`StorageColumnCount`) | 1 | 1–10 / 1 | Set the number of top-to-bottom columns used by chests, banks, and their actions. One preserves the original vertical list. |
| Shop columns (`ShopColumnCount`) | 1 | 1–10 / 1 | Set the number of top-to-bottom columns used by shop entries. One preserves the original vertical list. |
| Blocked movement bumps (`MovementBumpTonesEnabled`) | true | On / off | Thud once when a walk request stops making progress, repeating slowly while the direction stays blocked. A closed door answers higher and more hollow than terrain so it does not read as a dead end. The same cue reports landings, weighted by how far you fell, and contact with a ceiling overhead. |
| Blocked movement bump volume (`MovementBumpVolumePercent`) | 70 | 0–100 / 5 | Set blocked-movement bump loudness as a percentage of the game's Sound volume. |
| Wall tones (`WallToneEnabled`) | true | On / off | Continuously indicate nearby movement-blocking left walls, right walls, and the gravity-relative ceiling with procedural audio. Traversable steps and slopes stay silent, and each surface remains placed at its literal world position. |
| Wall tone volume (`WallToneVolumePercent`) | 70 | 0–100 / 5 | Set wall-tone loudness as a percentage of the game's Sound volume. |
| Wall tone range (`WallToneRangeTiles`) | 12 | 4–30 / 1 | Set the maximum sensing distance in tiles. A larger range begins indicating terrain sooner. |
| Reduce spatial cue volume with distance (`SpatialAudioDistanceAttenuationEnabled`) | true | On / off | Make wall and ceiling tones, hostile-mob tones, and radar pings quieter with distance. Disable this to keep those detected cues at full configured volume until their normal range cutoff; position and pitch remain spatial. |
| Climbing elevation cues (`ElevationMovementCuesEnabled`) | true | On / off | Play a brief rising or falling tick when crossing a vertical tile boundary while attached to a rope or similar climbable tile. Ordinary vertical movement stays silent. |
| Elevation movement cue volume (`ElevationMovementCueVolumePercent`) | 70 | 0–100 / 5 | Set ascending and descending tick loudness as a percentage of the game's Sound volume. |
| Ledge and drop warnings (`DropWarningsEnabled`) | true | On / off | Sound one safe or unsafe cue when walking toward a drop of at least three tiles. The warning does not repeat while you keep pressing toward the same ledge. |
| Drop warning volume (`DropWarningVolumePercent`) | 70 | 0–100 / 5 | Set safe and unsafe ledge-cue loudness as a percentage of the game's Sound volume. |
| Drop detection range (`DropDetectionRangeTiles`) | 30 | 3–60 / 1 | Set how far downward, from 3 to 60 tiles, Ariadne searches for a safe landing. Lava, shimmer, hurting tiles, damaging falls, and no bottom within this range are unsafe. |
| Ledge warning lookahead (`DropWarningLookaheadTiles`) | 4 | 1–12 / 1 | Set how many reachable tiles ahead, from 1 to 12, Ariadne checks for a ledge. The default is 4. Walls stop the search, while traversable steps and slopes do not. |
| Traversal landmark cues (`TraversalLandmarkCuesEnabled`) | true | On / off | Sound distinct spatial platform, minecart-track, and rope cues as grounded movement crosses their columns. Speech names only the start or change of a contiguous run. |
| Traversal landmark cue volume (`TraversalLandmarkCueVolumePercent`) | 70 | 0–100 / 5 | Set platform, minecart-track, and rope cue loudness as a percentage of the game's Sound volume. |
| Hostile and target cues (`HostileMobTonesEnabled`) | true | On / off | Play one continuous square tone for the enemy you are holding, or for the nearest enemy on screen when nothing is held, plus a separate cue when a target is taken or lost. The tone becomes louder as that enemy approaches, screen height alone controls its pitch, and a held enemy sounds a perfect fifth higher than an unheld one. |
| Hostile and target cue volume (`HostileMobToneVolumePercent`) | 70 | 0–100 / 5 | Set hostile-mob tone and combat-target lock cue loudness as a percentage of the game's Sound volume. |
| Hostile mob tone range (`HostileMobToneRangeTiles`) | 80 | 20–120 / 5 | Set the distance in tiles at which a hostile mob tone stops. With distance-based volume reduction enabled, loudness rises evenly from there to full at the player; with it disabled, the tone stays at configured volume throughout the range. |
| Freecam body beacon volume (`FreecamBeaconVolumePercent`) | 70 | 0–100 / 5 | Set the loudness of the periodic spatial pulse that points back to the live player while freecam is active. |
| Radar (`RadarEnabled`) | true | On / off | Sound a short bell from anything the scanner would list when it first comes into range. Apostrophe steps through one contact and matching ping at a time from a fixed snapshot that resets after four idle seconds. Manual snapshots always include dropped items. |
| Radar volume (`RadarVolumePercent`) | 70 | 0–100 / 5 | Set radar ping loudness as a percentage of the game's Sound volume. |
| Radar range (`RadarRangeTiles`) | 30 | 10–60 / 5 | Set how far in tiles the radar reaches. A ping is quietest at the edge of that range and loudest underfoot, so a shorter range makes each tile of approach a larger change. |
| Name radar contacts on a sweep (`RadarSweepSpeechEnabled`) | true | On / off | Speak the nearest contacts by name when the radar sweep key is pressed. Passive discovery stays tones only either way, and an empty sweep is always reported. |
| Radar finds ores and valuables (`RadarDetectsOresAndValuables`) | true | On / off | Detect the ground a Spelunker Potion would highlight: ore, gems, pots and life crystals. Sounds one strike. |
| Radar finds containers (`RadarDetectsContainers`) | true | On / off | Detect chests, barrels and dressers. Sounds two strikes. |
| Radar finds creatures (`RadarDetectsCreatures`) | true | On / off | Detect the town, rescuable and passive creatures a Hunter Potion would highlight. Sounds three strikes. |
| Radar finds enemies (`RadarDetectsEnemies`) | false | On / off | Detect hostile creatures as well. Off by default because the hostile mob tone already follows the nearest enemy continuously. Sounds four strikes. |
| Passive radar finds dropped items (`RadarDetectsDroppedItems`) | false | On / off | Detect items lying in the world automatically. Sounds four strikes. Manual apostrophe checks always include dropped items and stack counts, even when this is off. |
| Radar finds liquids (`RadarDetectsLiquids`) | false | On / off | Detect pools of water, lava, honey and shimmer. Sounds four strikes. |
| Radar finds trees and large plants (`RadarDetectsTreesAndPlants`) | false | On / off | Detect trees, cacti and other large plants. Sounds four strikes. |
| Radar finds placed objects (`RadarDetectsPlacedObjects`) | false | On / off | Detect furniture and other placed multi-tile objects. This is the busiest category indoors. Sounds four strikes. |
| Footstep sounds (`FootstepSoundsEnabled`) | true | On / off | Sound a step each time the player crosses a tile boundary on foot, raised in pitch while standing on a platform. |
| Footstep volume (`FootstepVolumePercent`) | 70 | 0–100 / 5 | Set footstep loudness as a percentage of the game's Sound volume. |
| Interaural time difference (`SpatialAudioItdEnabled`) | true | On / off | Add a small far-ear delay to wall tones, hostile and combat-target cues, the freecam body beacon, and cached native cursor earcons. Turning this off retains stereo level differences and vertical pitch. |
| Interaural time difference strength (`SpatialAudioItdStrengthMilliseconds`) | 0.65 | 0–1 / 0.05 | Set the global maximum far-ear delay in milliseconds. The full amount occurs at either horizontal viewport edge. |
| Head shadow (`SpatialAudioHeadShadowEnabled`) | false | On / off | Roll the treble off whichever ear the head is between, on top of the level difference the pan already applies. A real head takes the high frequencies and leaves the low ones. This changes the character of the stereo field, so compare it against the setting off before keeping it. |
